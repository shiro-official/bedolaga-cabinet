eBunny Cabinet 1.80.1 — оформление админки

База: присланный архив ebunny-cabinet-1.80.1.rar, без замены на другую версию.
Официальный проект BEDOLAGA-DEV/bedolaga-cabinet v1.80.1; лицензия AGPL-3.0 сохранена.

ЧТО ИЗМЕНИЛОСЬ
Отдельный слой src/styles/ebunny-admin.css действует только на /admin и вложенных маршрутах.
Шрифты, наклонный логотип, кремовая/графитовая темы, розовые и лаймовые акценты,
обводки панелей, кнопки, поля, таблицы и окна приведены к стилю eBunny.
Вместо общего анимированного фона админки — лёгкая точечная фактура.
Состояния ошибок, предупреждений и успешных действий сохраняют разные цвета.
Редактор тем сохраняет исходный предпросмотр палитры. При выходе из его вкладки
админка возвращается к eBunny. Настройки сохраняются существующими обработчиками.
Пользовательский кабинет по-прежнему использует фиксированную палитру eBunny.

ЧТО СОХРАНЕНО
Исходники пользовательских страниц, API, хранилищ, платежей, подписок и прав доступа
не изменены. Пользовательский ebunny.css оставлен без изменений.
В ThemeTab добавлено только включение/выключение визуального предпросмотра;
обработчики сохранения и сброса не менялись.
Общий провайдер темы и начальная загрузка палитры адаптированы для /admin.
Бот, база данных, Caddy и основной сайт не входят в обновление.

ПРОВЕРКИ
TypeScript и production build прошли.
39 тестов прошли: провайдер темы, редактор тем, состояние списка пользователей,
форма тарифа с бесплатным периодом.
Проверены семь экранов в браузере с вымышленными ответами API: главное меню
админки, пользователи, тарифы, выбор типа тарифа, новости, настройки и главная
пользовательского кабинета; тёмная/светлая темы, компьютер и телефоны 320/390 px.
Дополнительно проверены открытие формы тарифа, редактирование имени,
окно подтверждения удаления и возврат палитры после предпросмотра темы.
Проверки не обращались к реальному боту и не выполняли реальные платежи/удаления.
После установки проверьте свои данные и одну привычную операцию в админке.

УСТАНОВКА НА DE-13
Распакуйте в НОВУЮ папку, не смешивая со старой сборкой.
Из папки с install-ebunny.sh выполните:
  bash install-ebunny.sh
Скрипт сохранит текущий Compose и тег прежнего образа в /root/ebunny-cabinet-design-backup-ДАТА,
соберёт образ из готового dist, затем обновит только образ сервиса cabinet
в /opt/bedolaga-cabinet/docker-compose.yml. Порт 127.0.0.1:3000 сохранится.
Скачивать зависимости Node на сервере и собирать TypeScript не требуется.
После установки обновите my.ebunny.site через Ctrl+F5; Mini App закройте и откройте заново.
Если установка завершилась ошибкой — сохраните её вывод.

ОТКАТ
Скрипт выведет папку резервной копии. В ней лежат прежний docker-compose.yml,
image-id.txt и image-tag.txt. Укажите сохранённый тег из image-tag.txt в поле image
сервиса cabinet и выполните в /opt/bedolaga-cabinet:
  docker compose up -d --no-deps cabinet
Не используйте удаление томов или --remove-orphans.

ИСХОДНИКИ
В архиве есть исходники и готовый dist. Для разработки: npm ci, затем npm run build.
Исходный Dockerfile оставлен, установка использует Dockerfile.prebuilt.
Не обновляйте кастомную сборку официальным latest: он заменит оформление.
